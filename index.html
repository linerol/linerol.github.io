Ce sur quoi je suis utile

Faire cohabiter Flutter avec du code natif qui existait déjà

Le poids livré

Un SDK s'ajoute à l'application de quelqu'un d'autre. Chaque mégaoctet se négocie. J'automatise le nettoyage des moteurs Flutter et leur injection dans l'artefact final, en coupant les dépendances qui feraient retélécharger les binaires lourds côté client.

Gradle · Maven · llvm-strip · ABI filters

Le pont natif

Les applications hôtes parlent Kotlin et Swift, le SDK parle Dart. J'entretiens et j'étends un pont typé entre les deux, ainsi que l'intégration côté hôte : Fragment Android, ViewController iOS, ViewManagers React Native.

Pigeon · Kotlin · Swift · add-to-app

La release

Un tag déclenche tout : builds Android et iOS en parallèle, publication sur les registres, et une politique de signature propre aux SDK — livrer non signé, laisser l'app cliente signer, sans invalider la signature du moteur Flutter.

GitHub Actions · SPM · CocoaPods · npm
